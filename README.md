# Inżynieria finansowa 1: Projekt I

## Opis projektu

Głównym celem projektu jest implementacja i zbadanie efektywności strategii zabezpieczających sprzedaż waniliowych opcji europejskich kupna i sprzedaży. Rozpoczynamy od analizy instrumentu bazowego jakim jest indeks giełdowy *WIG20*, a następnie przedstawiamy metody symulowania jego notowań, które w późniejszych częściach posłużą do analiz efektywności strategii zabezpieczających. Główną z rozważanych strategii będzie standardowy delta-hedging - po ilościowej analizie jego dokładności przyjrzymy się alternatywnym strategiom, opartym na idei gamma-hedgingu.
